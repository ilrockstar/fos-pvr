# Методические указания обучающимся

**Дисциплина:** Прогнозирование временных рядов: от статистики до MLOps  
**Архитектура ФОС:** [project_guidelines.md](../../Project/project_guidelines.md)

---

## 1. Как устроен семестр

| Компонент | Что делаете | Вес |
|-----------|-------------|-----|
| **Milestones ЛР1–10** | Работаете **в команде** 3–4 чел., один репозиторий | 40 % |
| **ПЗ1–5** | Квизы и кейс **индивидually** | 10 % |
| **Forecast Cup** | Соревнование (часто та же команда) | 15 % |
| **PRC + peer-review** | Финальная защита MVP; оцениваете вклад коллег | 35 % |

Система оценивания: [docs/grading.md](../../docs/grading.md).

---

## 2. Роли в команде

Выберите роль в [уставе](../../Project/templates/project_charter.md): **Data Analyst**, **ML Engineer**, **ML Researcher**, **MLOps** (координатор команды — по договорённости).  
Матрица задач по milestones: [project_guidelines.md §3](../../Project/project_guidelines.md#3-формирование-команды-и-роли).

**Минимум от каждого:**

- ≥ 15 % commits (ориентир) или эквивалентный вклад в артефакты;
- выступление на защитах milestones и PRC (2–3 мин по своей зоне);
- заполнение peer-review после финала.

---

## 3. Выполнение лабораторных (milestones)

1. Прочитайте задание ЛР в модуле (M1–M4).
2. Согласуйте с командой **ответственного (R)** по RACI.
3. Реализуйте код и раздел отчёта `docs/report/0X_*.md`.
4. Сдайте по [шаблону milestone](../../Project/templates/milestone_report.md): commit hash + PDF при необходимости.
5. На защите (5–7 мин) докладчик — по таблице в guidelines.

**Не путайте:** ПЗ1–5 сдаются **самостоятельно** и не заменяют milestone команды.

---

## 4. Сдача и защита PRC

- Презентация 12–15 слайдов: [defense_outline.md](../../Project/templates/defense_outline.md).
- Live demo: сервис поднимается по `DEPLOY.md` за ≤ 5 мин.
- Итоговый отчёт 15–25 стр. (накопленный из milestones).
- Критерии: [Project/rubrics.md](../../Project/rubrics.md).

---

## 5. Использование LLM и внешних ресурсов

**Разрешено:**

- изучение документации библиотек, отладка, черновики текста;
- генерация **шаблонного** кода с последующей адаптацией и пониманием.

**Запрещено / недопустимо:**

- сдавать код или отчёт, который вы не можете объяснить на защите;
- загружать **данные партнёра** или конфиденциальные датасеты в публичные LLM;
- выдавать чужой или сгенерированный вклад за свой без указания.

**Обязательно:** раздел «Использованные инструменты» в README команды, если LLM существенно участвовал в коде.

Подробнее: [project_guidelines.md §10](../../Project/project_guidelines.md), [CONTRIBUTING.md](../../CONTRIBUTING.md).
