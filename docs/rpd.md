## 1. Общие сведения

| Поле | Значение |

## 2. Цель и задачи

**Цель:** сформировать системные компетенции по полному циклу разработки моделей прогнозирования временных рядов — от первичного анализа данных и статистического моделирования до методов машинного и глубокого обучения, промышленного развёртывания и мониторинга прогнозных систем.

### 2.1. Общие задачи

| № | Задача | Компетенции КРМ |
|---|--------|----------------|
| 1 | Освоить теоретические основы анализа и прогнозирования ВР | ML-2.1 |
| 2 | Получить практические навыки работы с реальными ВР на всех этапах жизненного цикла | BD-1.2, BD-1.3, ML-2.2 |
| 3 | Обоснованно выбирать методы прогнозирования в зависимости от свойств данных и бизнес-контекста | ML-3.2, ML-2.3 |
| 4 | Освоить инструментарий Data Scientist / ML Engineer: Python, Pandas, Statsmodels, Scikit-learn, PyTorch/TensorFlow, MLflow, Docker, FastAPI | PL-1, LC-5 |

## 4. Структура дисциплины

Дисциплина состоит из **4 модулей** и **16 тем** учебно-тематического плана.  
Лабораторные работы **ЛР1–10** — milestones сквозного проекта; **ПЗ1–ПЗ5**, **COP** (соревнование), **PRC** (защита MVP) и **peer-review** — формы контроля по [grading.md](grading.md).

**Обозначения в таблице:** **СОР** — соревнование Forecast Cup; **PRC** — командный проектный кейс; **k** — коэффициент peer-review (0,7–1,3 к части PRC).

## 5. Планируемые результаты обучения

### Знать

1. Понятия теории ВР: тренд, сезонность, стационарность, автокорреляция.
2. Классические модели: AR, MA, ARIMA, SARIMA, экспоненциальное сглаживание.
3. ML- и нейросетевые методы прогнозирования (регрессия, boosting, LSTM, TFT — обзорно).
4. Метрики качества и критерии выбора модели.
5. Data/concept drift и деградация моделей.
6. MLOps: контейнеризация, REST API, мониторинг, CI/CD.

### Уметь

1. Полный цикл анализа ВР (EDA, preprocessing, декомпозиция, стационарность).
2. ARIMA/SARIMA, диагностика остатков.
3. Регрессионные и ансамблевые модели (XGBoost, LightGBM).
4. LSTM/GRU для последовательностей.
5. Метрики MAE, RMSE, MAPE, SMAPE, MASE.
6. Выявление drift и организация retraining.
7. REST API и Docker для сервиса прогноза.
8. Мониторинг и версионирование (MLflow).

### Владеть

1. Python-стеком для ВР (Pandas, Statsmodels, Scikit-learn, PyTorch/TensorFlow).
2. Обоснованным выбором модели под данные и SLA.
3. Интерпретацией результатов (SHAP) и бизнес-рекомендациями.
4. Воспроизводимыми экспериментами (MLflow, DVC).
5. Разработкой и деплоем прогнозных сервисов.
6. **Командной работой** над проектом полного цикла (роли Data Analyst / ML Engineer / ML Researcher / MLOps).
