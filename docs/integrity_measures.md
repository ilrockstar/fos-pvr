## Рекомендации преподавателю

1. **ЛР:** на каждой защите milestone — минимум **одна «модификация на лету»** + [вопросы по ролям](lab_defense_questions.md).
2. **ПЗ:** при обновлении квизов — минимум **1–2 «ловушки»** на график/логику, не на зубрёжку API.
3. **COP:** public LB — для обратной связи; **зачёт и рейтинг** — только private + проверка ноутбука.
4. **PRC:** каждый участник отвечает **минимум 2 мин** по своей роли; блиц по артефактам в репозитории.
5. **Peer-review:** открывать форму сразу после защиты (48–72 ч); сверять с git log.
