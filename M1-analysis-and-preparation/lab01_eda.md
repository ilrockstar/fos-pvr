## Краткая теоретическая справка

**Временной ряд** — последовательность наблюдений $y_t$, упорядоченных во времени. Перед построением модели необходимо понять структуру ряда:

- **Тренд** — долгосрочная направленность (рост/падение).
- **Сезонность** — повторяющийся паттерн с известным периодом $s$ (7 для недели, 365 для года).
- **Цикличность** — колебания без фиксированного периода.
- **Шум** — случайная составляющая.
- **Аномалии** — точки, существенно отклоняющиеся от типичного поведения.

**Автокорреляция** — корреляция ряда с его лагами. Функция ACF показывает зависимость $y_t$ от $y_{t-k}$; PACF — «чистую» связь с лагом $k$ без учёта промежуточных лагов. Анализ ACF/PACF помогает выбрать класс модели (AR, MA, ARIMA) на следующих этапах.

## Фрагменты кода

### Загрузка и подготовка индекса

```python
import pandas as pd
import matplotlib.pyplot as plt

# df — результат вашей загрузки; адаптируйте путь и имена столбцов
df["date"] = pd.to_datetime(df["date"])
df = df.sort_values("date").set_index("date")
df = df.asfreq("D")  # суточная частота; проверьте, появились ли NaN

print(df.info())
print(f"Период: {df.index.min()} — {df.index.max()}, N = {len(df)}")
print(f"Пропуски: {df['load_mwh'].isna().sum()}")
```

### Базовая визуализация

```python
fig, axes = plt.subplots(2, 1, figsize=(12, 6), sharex=False)
df["load_mwh"].plot(ax=axes[0], title="Суточное потребление — полный ряд")
df["load_mwh"].loc["2022-01-01":"2022-01-31"].plot(ax=axes[1], title="Фрагмент: январь 2022")
plt.tight_layout()
plt.savefig("reports/lab01_timeseries_overview.png", dpi=150)
```

### Seasonal plot по дню недели

```python
df_plot = df.copy()
df_plot["dow"] = df_plot.index.dayofweek  # 0 = понедельник
df_plot.groupby("dow")["load_mwh"].mean().plot(kind="bar", title="Средняя нагрузка по дню недели")
```

### ACF / PACF

```python
from statsmodels.graphics.tsaplots import plot_acf, plot_pacf

fig, axes = plt.subplots(1, 2, figsize=(12, 4))
plot_acf(df["load_mwh"].dropna(), lags=60, ax=axes[0])
plot_pacf(df["load_mwh"].dropna(), lags=60, ax=axes[1], method="ywm")
plt.savefig("reports/lab01_acf_pacf.png", dpi=150)
```

### Поиск выбросов (IQR)

```python
q1, q3 = df["load_mwh"].quantile([0.25, 0.75])
iqr = q3 - q1
lower, upper = q1 - 3 * iqr, q3 + 3 * iqr
outliers = df[(df["load_mwh"] < lower) | (df["load_mwh"] > upper)]
print(f"Выбросов (IQR×3): {len(outliers)}")
```
