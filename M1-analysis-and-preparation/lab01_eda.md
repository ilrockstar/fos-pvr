## 4. Теоретическая справка

**Временной ряд** — последовательность наблюдений $y_t$, упорядоченных во времени.

| Компонента | Описание |
|------------|----------|
| **Тренд** | Долгосрочная направленность (рост/падение) |
| **Сезонность** | Повторяющийся паттерн с периодом $s$ (7 — неделя, 365 — год) |
| **Цикличность** | Колебания без фиксированного периода |
| **Шум** | Случайная составляющая |
| **Аномалии** | Точки, существенно отклоняющиеся от типичного поведения |

**ACF** — автокорреляция $y_t$ с $y_{t-k}$; **PACF** — «чистая» связь с лагом $k$ без промежуточных лагов. Анализ ACF/PACF помогает выбрать класс модели (AR, MA, ARIMA) на этапах ЛР3–4.

## 5. Ход работы

### Этап 1. Загрузка и первичный осмотр

1. Скачайте данные ENTSO-E (или альтернативный источник) за ≥ 3 лет.

3. Проверьте типы, диапазон дат, число пропусков и дубликатов.
4. Сохраните сырой CSV в `data/raw/load_daily_raw.csv`.

### Этап 2. Визуальный анализ

1. Линейный график всего ряда.
2. Фрагменты: один месяц, одна неделя.
3. **Seasonal plot** (среднее по дню года или дню недели).
4. **Boxplot** по месяцам или дням недели.

### Этап 3. Числовые характеристики

### Этап 4. Выявление аномалий

1. Точки, где $|y_t - \text{median}| > 3 \cdot \text{IQR}$.
2. Сопоставление с известными событиями (праздники, локдауны).

### Этап 5. Аналитическая записка

Разделы отчёта (2–3 стр.):

1. Описание данных (источник, период, частота).
2. Тренд и сезонность (период $s$).
3. Характер автокорреляции (затухание ACF).
4. Проблемы: пропуски, выбросы, смена режима.
5. Рекомендации для [ЛР2](lab02_preprocessing_decomposition.md).

### Фрагменты кода

```python
import pandas as pd
import matplotlib.pyplot as plt
from statsmodels.graphics.tsaplots import plot_acf, plot_pacf

df = pd.read_csv("data/raw/load_daily_raw.csv", parse_dates=["date"])
df = df.sort_values("date").set_index("date").asfreq("D")

print(f"Период: {df.index.min()} — {df.index.max()}, N = {len(df)}")
print(f"Пропуски: {df['load_mwh'].isna().sum()}")

fig, axes = plt.subplots(1, 2, figsize=(12, 4))
plot_acf(df["load_mwh"].dropna(), lags=60, ax=axes[0])
plot_pacf(df["load_mwh"].dropna(), lags=60, ax=axes[1], method="ywm")
plt.savefig("reports/lab01_acf_pacf.png", dpi=150)

q1, q3 = df["load_mwh"].quantile([0.25, 0.75])
iqr = q3 - q1
outliers = df[(df["load_mwh"] < q1 - 3 * iqr) | (df["load_mwh"] > q3 + 3 * iqr)]
print(f"Выбросов (IQR×3): {len(outliers)}")
```
