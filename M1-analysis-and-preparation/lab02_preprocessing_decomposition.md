## 4. Теоретическая справка

| Метод | Назначение |
|-------|------------|
| **Imputation** | Заполнение пропусков: interpolate, ffill, сезонная imputation |
| **Выбросы** | Замена, winsorization, clipping — с документированием |
| **STL** | $y_t = T_t + S_t + R_t$ (тренд + сезонность + остаток) |
| **ADF** | H₀: единичный корень → нестационарен |
| **KPSS** | H₀: стационарен (используется совместно с ADF) |
| **Дифференцирование** | $\Delta y_t = y_t - y_{t-1}$; сезонное: $\Delta_s y_t = y_t - y_{t-s}$ |

> Параметры **fit** scaler/normalizer — только на train (важно с ЛР6–7).

## 5. Ход работы

### Этап 1. Пропуски и выбросы

1. Загрузите ряд из ЛР1.
2. Заполните пропуски (обоснуйте метод).

### Этап 2. STL-декомпозиция

1. Период $s=7$; при длине ряда ≥ 2 лет — сравните с $s=365$.
2. Визуализируйте trend, seasonal, residual.
3. Оцените долю дисперсии компонент.

### Этап 3. Стационарность

1. ADF и KPSS для исходного ряда.
2. При необходимости: $d=1$, сезонное $D=1$.
3. ACF/PACF стационаризированного ряда.

### Этап 4. Сохранение

1. `data/processed/load_daily_clean.csv`.
2. `preprocessing_meta.json`: imputation, outliers, $d$, $D$, $s$.
3. «Паспорт ряда» (½ стр.) для команды ML.

### Фрагменты кода

```python
import json
import pandas as pd
from statsmodels.tsa.seasonal import STL
from statsmodels.tsa.stattools import adfuller, kpss

df = pd.read_csv("data/raw/load_daily_raw.csv", parse_dates=["date"], index_col="date")
df["load_mwh"] = df["load_mwh"].interpolate(method="time")

stl = STL(df["load_mwh"].dropna(), period=7, robust=True).fit()
stl.plot()

adf = adfuller(df["load_mwh"].dropna())
kpss_stat = kpss(df["load_mwh"].dropna(), regression="c", nlags="auto")
print(f"ADF p={adf[1]:.4f}, KPSS p={kpss_stat[1]:.4f}")

meta = {"seasonal_period": 7, "d": 1, "D": 0, "imputation": "time_interpolate"}
df[["load_mwh"]].to_csv("data/processed/load_daily_clean.csv")
with open("data/processed/preprocessing_meta.json", "w") as f:
    json.dump(meta, f, indent=2)
```
