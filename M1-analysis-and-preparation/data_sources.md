# Сквозной датасет для лабораторных работ

Все лабораторные работы дисциплины выполняются на **одном временном ряду**, чтобы студент прошёл полный цикл прогнозирования — от EDA до деплоя.

---

## Основной ряд: суточное потребление электроэнергии

| Параметр | Значение |
|----------|----------|
| **Предметная область** | Прогноз нагрузки энергосистемы для оперативного планирования |
| **Источник** | [ENTSO-E Transparency Platform](https://transparency.entsoe.eu) |
| **Регион** | Germany (DE) или France (FR) — на выбор преподавателя |
| **Периодичность** | Суточная (агрегация часовых данных) |
| **Рекомендуемый период** | ≥ 3 лет (≈ 1100+ наблюдений) |
| **Целевая переменная** | `load_mwh` — суммарное суточное потребление, МВт·ч |

### Дополнительный ряд (с ЛР4)

| Параметр | Значение |
|----------|----------|
| **Переменная** | `temp_c` — среднесуточная температура, °C |
| **Источник** | [Open-Meteo Archive API](https://open-meteo.com/en/docs/historical-weather-api) (бесплатно, без ключа) |
| **Назначение** | Экзогенный признак для регрессионных и ML-моделей |

---

## Структура артефактов семестра

Студент ведёт единую папку проекта (рекомендуемое имя: `ts-forecast-labs/`):

```
ts-forecast-labs/
├── data/
│   ├── raw/              # исходные выгрузки
│   ├── processed/        # очищенный ряд после ЛР2
│   └── features/         # признаковые таблицы (с ЛР4)
├── notebooks/            # или src/ — ноутбуки/скрипты по ЛР
├── models/               # сохранённые модели (с ЛР3)
├── reports/              # отчёты по лабораторным
└── README.md             # описание проекта
```

**Ключевой файл после ЛР2:** `data/processed/load_daily_clean.csv` — используется во всех последующих работах.

## Альтернативные источники

Если доступ к ENTSO-E затруднён, допускается замена на эквивалентный ряд при сохранении свойств (тренд + годовая сезонность + ≥ 500 точек):

| Источник | Ряд | Ссылка |
|----------|-----|--------|
| UCI ML Repository | Individual household electric power (агрегация до суток) | [archive.ics.uci.edu](https://archive.ics.uci.edu) |
| Kaggle | Hourly energy consumption (агрегация) | [kaggle.com/datasets](https://www.kaggle.com/datasets) |
| FRED | Total Energy Consumption | [fred.stlouisfed.org](https://fred.stlouisfed.org) |

При замене источника студент **обязан** указать это в README проекта и сохранить ту же структуру артефактов.

---

## Минимальные требования к ряду

- не менее **500** наблюдений с фиксированной периодичностью;
- явно выраженная **суточная/недельная/годовая** сезонность (хотя бы одна);
- отсутствие «дыр» более 5 % без обработки (заполняются в ЛР2);
- описание источника и периода в каждом отчёте.
