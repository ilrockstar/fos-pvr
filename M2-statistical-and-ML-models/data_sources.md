## Самостоятельный сбор данных

Студент может собрать мини-ряд (30+ наблюдений) из личного опыта:

- Ежедневные расходы / доходы (приложение «Дзен-мани», Excel)
- Посещаемость спортзала / шаги (Apple Health, Google Fit)
- Цены на продукты в соседнем магазине (еженедельно, 2–3 месяца)
- Температура / осадки (API OpenWeatherMap, [openweathermap.org](https://openweathermap.org))
- Просмотры соцсетей / подписчики (встроенная аналитика)
- Данные с места практики / стажировки (с согласия руководителя)

**Минимальные требования к самособранному ряду:**
- не менее 30 наблюдений;
- фиксированная периодичность;
- описание источника и метода сбора в отчёте.

## Рекомендации по выбору данных

| Задача | Подходящий тип ряда |
|--------|---------------------|
| ARIMA / SARIMA | Ряд с трендом и/или сезонностью (Air Passengers, электроэнергия) |
| Экзогенные переменные | Макроэкономика (ВВП + инфляция + ставка) |
| ML-сравнение | Длинный ряд (200+ точек): цены акций, курс валют |
| Календарные признаки | Дневные данные с выходными/праздниками |
| Самостоятельный сбор | Любой личный ряд с понятной предметной областью |
