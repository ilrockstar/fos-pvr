## Если… → то…

| Условие | Рекомендуемая модель | Почему |
|---------|---------------------|--------|
| Ряд стационарен, PACF обрывается после лага p | AR(p) | Прямая зависимость от прошлых значений |
| Ряд стационарен, ACF обрывается после лага q | MA(q) | Зависимость от прошлых ошибок |
| Есть тренд, нет сезонности | ARIMA(p,d,q) | Дифференцирование убирает тренд |
| Есть тренд + сезонность | SARIMA / Exp. Smoothing | Сезонное дифференцирование или сезонные компоненты |
| Мало данных (< 50 точек) | AR / MA / ARIMA / ES | ML переобучится |
| Много данных (200+), есть признаки | Random Forest / Boosting | ML использует нелинейные зависимости |
| Нужна интерпретация факторов | Линейная регрессия / ARIMAX | Коэффициенты имеют смысл |
| Нужна максимальная точность, интерпретация не важна | Gradient Boosting | Лучшие метрики на табличных данных |
| Быстрый baseline | Скользящее среднее / Exp. Smoothing | Минимум параметров, быстрый результат |

---

## Дерево решений

```
Есть сезонность?
├── Да → Период известен?
│   ├── Да → SARIMA или Holt-Winters
│   └── Нет → ARIMA + календарные признаки (ML)
└── Нет → Есть тренд?
    ├── Да → ARIMA (d≥1) или Exp. Smoothing
    └── Нет → ARMA или ML с лагами

Достаточно данных для ML (>100 точек)?
├── Да → Сравнить ARIMA/SARIMA с RF/Boosting
└── Нет → Только статистические модели
```

## Красные флаги

| Симптом | Вероятная проблема | Что делать |
|---------|-------------------|------------|
| Остатки с паттерном | Модель не уловила структуру | Добавить сезонность / признаки |
| AIC сильно лучше при большом p | Переобучение | Использовать BIC, упростить |
| ML намного лучше ARIMA | Возможна утечка данных | Проверить признаки |
| Все модели плохие | Ряд непредсказуем / мало данных | Сообщить заказчику ограничения |
