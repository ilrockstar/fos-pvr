## 2. Проведение устных форматов

### Коллоквиум (задания №1, №9)

1. Студент получает материалы за 10 мин до ответа (графики / данные).
2. 10 мин подготовка, 15–20 мин диалог.
3. Минимум 3 уточняющих вопроса от преподавателя.
4. Фиксировать уровень сразу после ответа по рубрике.

**Совет:** Не задавайте вопросы, на которые можно ответить одним словом. Хороший вопрос: *«Вы выбрали d=1. Что будет, если взять d=2?»*

### Защита мини-работы (задания №4, №11, №17)

1. Студент приносит готовый результат (ноутбук / слайды).
2. 5 мин презентация, 5 мин вопросы.
3. Ключевой вопрос всегда: *«Почему сделано именно так?»*

### Дебаты (задания №3, №16)

1. Разделить группу пополам (или на 2 команды по 3 человека).
2. 5 мин подготовка аргументов.
3. 15 мин дебаты (по 2 мин на реплику).
4. 5 мин — провокационный вопрос преподавателя.
5. 5 мин — голосование аудитории (необязательно, для вовлечения).

### Шкала

| Базовый | 60% | Зачтено с замечаниями |
| Средний | 80% | Зачтено |

### Вес заданий (рекомендация)

| Категория | Вес | Задания |
|-----------|-----|---------|
| Практические кейсы | 40% | №2, 7, 8, 15, 18 |
| Устные форматы | 25% | №1, 4, 9, 11, 17 |
| Дискуссии / ролевые | 20% | №3, 5, 10, 14, 16, 20 |
| Портфолио | 15% | №6, 13, 19 |

### Накопительная система

Каждое задание = 5 баллов (max). Итого за модуль: 60–100 баллов (при 12 заданиях — 60 max).

```
Итог модуля = сумма баллов / (число заданий × 5) × 100%
```

## 5. Типичные ошибки студентов

| Ошибка | Как выявить | Вопрос на защите |
|--------|-------------|------------------|
| Случайный train/test split | Метрика подозрительно хорошая | «Почему вы не перемешивали? Что будет, если перемешать?» |
| Утечка данных | Лаг 0 или target в признаках | «Какие признаки доступны в момент прогноза?» |
| Переобучение ARIMA | ARIMA(5,1,4) на 50 точках | «Сколько параметров вы оцениваете? Достаточно ли данных?» |
| Игнорирование сезонности | Плохие остатки с паттерном | «Видите ли вы паттерн в остатках? Что он означает?» |
| Сравнение без baseline | «RF лучше всего» без ARIMA | «А простое среднее? АRIMA? Чем вы сравнивали?» |

## 7. Материалы для подготовки графиков ACF/PACF (задание №1)

Преподаватель может заранее подготовить 3 пары графиков:

```python
# Пример генерации учебных графиков
import numpy as np
import matplotlib.pyplot as plt
from statsmodels.graphics.tsaplots import plot_acf, plot_pacf

np.random.seed(42)

# AR(1): phi=0.7
ar1 = np.zeros(200)
for t in range(1, 200):
    ar1[t] = 0.7 * ar1[t-1] + np.random.randn()

# MA(1): theta=0.6
ma1 = np.random.randn(200)
for t in range(1, 200):
    ma1[t] += 0.6 * ma1[t-1]

# ARMA(1,1)
arma11 = np.zeros(200)
e = np.random.randn(200)
for t in range(1, 200):
    arma11[t] = 0.5 * arma11[t-1] + e[t] + 0.4 * e[t-1]

for name, series in [('AR1', ar1), ('MA1', ma1), ('ARMA11', arma11)]:
    fig, axes = plt.subplots(1, 2, figsize=(10, 3))
    plot_acf(series, lags=20, ax=axes[0])
    plot_pacf(series, lags=20, ax=axes[1])
    fig.suptitle(name)
    plt.savefig(f'acf_pacf_{name}.png', dpi=150)
```

Студенту показывают графики **без подписи** модели — он должен определить тип.
