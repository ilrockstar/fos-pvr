# Ключ ПЗ5 «Сломай модель» (преподавателю)

## Обязательные элементы (60 %)

- [ ] Один понятный сценарий (level shift / сезонность / пропали exog)
- [ ] Ошибка выросла (число или «~в N раз»)
- [ ] Есть идея, **когда** переобучать

## Средний (80 %)

- [ ] Простой порог (MAE +X % за N дней)
- [ ] Окно данных для retrain (например, 90 дней)
- [ ] Связь с мониторингом команды или графиком ошибки

## Продвинутый (100 %)

- [ ] Реалистичная **задержка** обнаружения
- [ ] Проверка перед deploy / откат, если хуже
- [ ] Корректно назван data vs concept drift (если применимо)

## Типичные ошибки

- Только «переобучим раз в месяц» без триггера
- Нет количественной деградации
- Путают data и concept drift
