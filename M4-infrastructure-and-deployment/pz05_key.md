# Ключ ПЗ5 «Сломай модель» (преподавателю)

## Обязательные элементы (60 %)

- [ ] Описан сценарий изменения данных
- [ ] Метрика до/после (число или % роста)
- [ ] Упомянут retraining

## Средний (80 %)

- [ ] Data vs concept drift назван верно
- [ ] Порог алерта (PSI или MAE)
- [ ] Окно retrain

## Продвинутый (100 %)

- [ ] Задержка детекции (дней)
- [ ] Rollback / shadow validation
- [ ] Связь с team `monitoring.md`

## Типичные ошибки

- Только «переобучим» без триггера
- Нет количественной деградации
- Путают data и concept drift
