## 1. Цель и задачи

**Цель:** научиться выявлять уязвимости прогнозной модели, моделировать сценарии деградации и разрабатывать стратегию автоматического восстановления качества.

**Задачи:**

1. Выбрать обученную модель из группового проекта.
2. Разработать **≥ 3** сценария изменения данных, приводящих к деградации прогнозов (**ухудшение MAE или RMSE ≥ 25 %** относительно эталона).
3. Реализовать скрипт, применяющий сценарии к тестовым данным.
4. Оценить изменение метрик до и после применения каждого сценария.
5. Выбрать один **реалистичный** «победивший» сценарий и предложить стратегию ретренинга.
6. **Продемонстрировать восстановление** качества после переобучения.
7. Описать пороги мониторинга и срабатывания retrain.

## 2. Теоретическая справка

### Типы дрейфа

| Тип | Описание | Пример |
|-----|----------|--------|
| **Data drift** | Меняется распределение входных признаков | Нагрузка выросла на 30 % после рекламной кампании |
| **Concept drift** | Меняется связь признаков с целевой переменной | Влияние погоды на спрос изменилось после пандемии |

### Критерии деградации (ориентиры)

- ухудшение **MAE** или **RMSE** на **≥ 25 %** относительно эталона на hold-out;
- появление **систематического смещения** ошибок;
- для бизнес-метрик — рост **MAPE / SMAPE > 20 %**.

### Стратегии ретренинга

| Стратегия | Когда применять |
|-----------|-----------------|
| **Периодическая** (по расписанию) | Данные меняются плавно |
| **По триггеру** (при обнаружении drift) | Резкие непредсказуемые изменения |
| **Гибридная** | Критичные production-системы |

### Этап 2. Сценарии дрейфа (≥ 3)

Разработайте минимум **три** различных сценария. Примеры:

| ID | Сценарий | Описание | Пример реализации |
|----|----------|----------|-------------------|
| А | **Mean shift** | Сдвиг уровня ряда | `value *= 1.3` |
| Б | **Noise injection** | Усиление шума | `value += N(0, σ)` |
| В | **Seasonal shift** | Сдвиг сезонной фазы | `shift(period)` |
| Г | **Sudden spike** | Резкий аномальный пик | `value[100:120] *= 2` |
| Д | **Trend change** | Постепенное изменение тренда | `value += linspace(0, k, n)` |

Сохраните функции в `scripts/apply_drift_<фамилия>.py`:

```python
import numpy as np
import pandas as pd

def apply_mean_shift(df: pd.DataFrame, col: str, factor: float = 1.5) -> pd.DataFrame:
    out = df.copy()
    out[col] = out[col] * factor
    return out

def apply_noise(df: pd.DataFrame, col: str, noise_std: float = 5.0) -> pd.DataFrame:
    out = df.copy()
    out[col] = out[col] + np.random.default_rng(42).normal(0, noise_std, len(df))
    return out

```

### Этап 3. Оценка деградации

Для **каждого** сценария:

1. Примените сценарий к тестовым данным.
2. Получите прогноз на «сломанных» данных.
3. Рассчитайте MAE / RMSE и **процент деградации**:

$$\text{degradation\_\%} = \frac{\text{MAE}_{drift} - \text{MAE}_{baseline}}{\text{MAE}_{baseline}} \times 100$$

4. Сведите результаты в **таблицу** (сценарий · MAE · RMSE · degradation %).

### Этап 4. «Победивший» сценарий

Выберите **один** сценарий, который:

- даёт деградацию **≥ 25 %** по MAE или RMSE;
- выглядит **правдоподобно** для вашего бизнес-кейса (отказ датчика, аномальный пик нагрузки, сдвиг распределения).

Обоснуйте выбор в отчёте (3–5 предложений). При возможности — покажите **алерт** на дашборде команды ([ЛР10](lab10_monitoring.md)).

### Этап 5. Retraining и восстановление

1. Добавьте дрейфовые наблюдения (или актуальное окно) в обучающую выборку.
2. Переобучите модель (или выполните упрощённый retrain по правилам [ЛР8](../M3-neural-networks/lab08_validation_drift.md)).
3. Оцените качество **новой** модели на тех же «сломанных» данных.
4. Покажите, что метрики **вернулись** ближе к baseline (или объясните, почему нет).

Опишите **стратегию мониторинга**: порог срабатывания (например, «MAE вырос на 25 % за 7 дней»), окно данных для retrain (например, 90 дней), проверка перед deploy.
