# Фонд оценочных средств по дисциплине «Прогнозирование временных рядов: от статистики до MLOps»

Этот репозиторий предназначен для открытого и воспроизводимого представления фонда оценочных средств (ФОС) по дисциплине «Прогнозирование временных рядов: от статистики до MLOps». Здесь объединены рабочая программа дисциплины, модель измерения результатов обучения, контрольно-измерительные материалы (КИМ), критерии оценивания, методические рекомендации и используемые образовательные ресурсы. Результаты обучения связываются с компетентностно-ролевой моделью в области искусственного интеллекта (КРМ версии 3.0).

## 1. О дисциплине

**Цель дисциплины.**
- Дисциплина формирует системные компетенции по полному циклу разработки моделей прогнозирования временных рядов — от первичного анализа данных и статистического моделирования до применения методов машинного и глубокого обучения, а также промышленного развертывания и мониторинга прогнозных систем.

**Основные задачи.**
- Сформировать навыки анализа структуры временных рядов, выявления тренда, сезонности, шума и аномалий.
- Научить применять классические статистические методы прогнозирования и методы машинного обучения.
- Сформировать умения сравнивать модели по метрикам качества и анализировать их устойчивость.
- Освоить нейросетевые подходы к прогнозированию временных рядов.
- Сформировать навыки проектирования REST API, контейнеризации инференса и мониторинга дрейфа данных в продуктивной среде.


**Структура и содержание.** 
- Дисциплина состоит из 4 модулей: 
    - Анализ и подготовка ВР;
    - Статистические и ML-модели;
    - Нейросети и устойчивость;
    - Инфраструктура и деплой.
**Формат обучения:** лекции + **групповой сквозной проект** (3–4 человека); лабораторные работы = **milestones** проекта.  
**Форма аттестации:** дифференцированный **зачёт** (не экзамен).

**Пререквизиты и связи с другими дисциплинами.**
- В курсе используются знания и навыки следующих дисциплин:
    - Математический анализ;
    - Линейная алгебра;
    - Теория вероятностей;
    - Математическая статистика;
    - Программирование на Python;
    - Основы анализа данных;
    - Основы машинного обучения;
    - Инструменты анализа данных в Python;
    - Нейросетевые модели;
    - Веб-программирование, основы API;
    - Основы контейнеризации и DevOps;
    - Базы данных и SQL;


**Планируемые результаты обучения.** 
- По завершении дисциплины обучающийся сможет:
    - Проводить полный цикл анализа временного ряда (EDA, предобработка, декомпозиция, проверка стационарности);
    - Строить и настраивать ARIMA/SARIMA-модели, выполнять диагностику остатков;
    - Применять регрессионные и ансамблевые модели (XGBoost, LightGBM) для прогнозирования ВР;
    - Применять нейросетевые модели (LSTM, GRU, TFT) для прогнозирования последовательностей;
    - Оценивать качество моделей с использованием метрик (MAE, RMSE, MAPE, SMAPE, MASE);
    - Выявлять дрейф данных и организовывать цикл дообучения модели;
    - Разрабатывать REST API и контейнеризировать сервис прогнозирования (Docker).


Полное описание приведено в [РПД](docs/rpd.docx).
